# Raidbound

A high-fantasy raid card game. One to four heroes, each with their own deck, take on a raid boss that plays a deck of its own. Build a party, gear up with weapons and armour, complete quests, and bring down the boss for treasure.

## Play

- **Online:** https://raidbound.onrender.com — a small page that loads pictures only as they are needed, so it starts fast.
- **Offline:** download `public/Raidbound.html` (or use the *Download to play offline* link on the title screen) and double-click it. Every picture is packed inside, so it needs no internet.

Progress (collection, decks, loot codes, cosmetics) is saved in your browser.

## The game

- **6 heroes:**
  - Silver Concord: Ser Aldric (Paladin), Thorgrim (Ranger), Lyssara (Mage).
  - Ember Clans: Grukka (Warrior), Hruna (Priest), Snix (Rogue).

  Each hero has a once-per-game power, and their traits decide which cards their deck can hold.
- **Card types:** allies, abilities (basic and instant), weapons with strike costs, armour in six slots, items, quests, locations, master heroes and loot cards with scratch-off codes.
- **3 raids:**
  - Crypt of the Hollow King
  - The Molten Spire
  - The Sunken Cathedral

  Each raid has a 20-card boss deck, custom rules and phase changes. Its treasure pack holds holofoils and a chance of loot.
- **Party play:** up to four heroes share one device. Any seat can be run by the AI, and the boss scales with party size.
- **Deck builder, collection and vault:** loot codes unlock card backs, table themes and companion pets.

## Building from source

The game is plain JavaScript and CSS in `src/`. You need Python 3 to bundle it:

```
python build.py        # optimises gen/*.webp and writes dist/raidbound.html (single file) and dist/web/ (index.html + art/)
python gen_photos.py   # rebuilds src/art_photos.js after you change photos/*.jpg
node tools/sim.js 20   # optional: AI-vs-boss balance simulation (20 games per matchup)
```

| File | What it does |
|---|---|
| `src/art_core.js` | Scene palettes, photo backdrops and grading, scenery, particles |
| `src/art_fig.js` | Poses, race proportions, weapons, creatures |
| `src/art_hero.js` | Painted heroic figures: shaded anatomy, faces, armour sets, painted wolves and bears |
| `src/art_obj.js` | Items, armour pieces, weapon showcases and spell effects |
| `src/art_photos.js` | Generated by `gen_photos.py`: embedded backdrop photos and credits |
| `src/data.js` | Heroes, cards, boss decks, raids, cosmetics and character colour schemes |
| `src/engine.js` | Rules engine (works in the browser and in Node) |
| `src/ai.js` | AI player, deck building and starter decks |
| `src/ui_*.js`, `src/style.css` | Screens, battle board, treasure packs |

All card art is drawn in code as SVG. To recolour a character, edit `HEROLOOK`, `CLASSLOOK` or `LOOK` near the end of `src/data.js`.
